# Realtime Multi-Room Chat App

A modern realtime chat application built using React, Firebase Authentication, Firestore, and Tailwind CSS.

Users can:
- Create accounts
- Login using Email/Password
- Login using Google Account
- Join chat rooms
- Send realtime messages
- See typing indicators
- Chat with multiple users in realtime

---

# Tech Stack

## Frontend
- React + Vite
- Tailwind CSS

## Backend Services
- Firebase Authentication
- Cloud Firestore

## Deployment
- Vercel

---

# Features

- Email & Password Authentication
- Google Sign-In Authentication
- Realtime Messaging
- Multi-Room Chat System
- Typing Indicator
- Responsive UI
- Firebase Firestore Database
- Protected Chat Access
- Modern Clean Interface
